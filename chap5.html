     Chapter 5: Programming Concepts and Logic

Definition of Programming
Programming is the process of writing, testing, and maintaining a step-by-step set of instructions (code) that tells a computer how to solve a specific problem or perform a task.

Programming Language Generations

Low-Level Languages: Include Machine Language (1st Gen, binary code using 0s and 1s) and Assembly Language (2nd Gen, uses mnemonic codes). They are hardware-dependent and execute quickly.

High-Level Languages: 3rd Generation and beyond (e.g., C, C++, Java, Python). They use human-readable words, are hardware-independent, and are easy to learn and debug.

Language Translators

Compiler: Translates the entire high-level source code into machine code all at once before execution.

Interpreter: Translates and executes high-level source code line-by-line.

Assembler: Translates assembly language programs into machine code.

Program Design and Logic Tools

Algorithm: A clear, finite, step-by-step sequence of instructions written in plain language to solve a problem.

Flowchart: A diagrammatic representation of an algorithm using standard geometrical symbols (like ovals, rectangles, and diamonds) connected by flow lines.

Pseudocode: An informal, high-level outline of a computer program that combines plain natural language with programming structures.

Basic Control Structures

Sequence: Executing instructions one after another in order.

Selection (Decision): Executing different code branches based on conditions (e.g., IF-ELSE statements).

Iteration (Looping): Repeating a block of code multiple times until a condition is met (e.g., FOR, WHILE loops).
