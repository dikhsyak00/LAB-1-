Chapter 1: Computer System

     Definition of a Computer System
A computer system is an electronic device that accepts raw data as input, processes it according to stored instructions, produces useful information as output, and stores it for future use.

Fundamental Components (Hardware)
A computer system consists of four primary hardware components:

Input Devices: Tools used to enter data and commands into the computer.
Examples: Keyboard, Mouse, Scanner, Microphone.

Central Processing Unit (CPU): The brain of the computer that performs all calculations and data processing.
ALU (Arithmetic Logic Unit): Performs mathematical calculations and logical comparisons.
CU (Control Unit): Directs and coordinates all operations within the system.
Registers: High-speed temporary storage locations inside the CPU.

Output Devices: Tools that display or produce the processed information for the user.
Examples: Monitor, Printer, Speaker.

Memory and Storage:
Primary Memory (Main Memory): Temporary storage used directly by the CPU while processing.
RAM (Random Access Memory): Volatile (loses data when powered off).
ROM (Read-Only Memory): Non-volatile (retains data permanently).
Secondary Storage: Permanent storage used to keep files and applications long-term.
Examples: SSD, HDD, USB Flash Drive.

Computer Software
Software is the set of instructions or programs that tell the hardware how to perform tasks.

System Software: Manages and controls hardware operations (e.g., Operating Systems like Windows, macOS, Linux).

Application Software: Performs specific tasks for the user (e.g., Web Browsers, Word Processors, Games).

Basic Flow of Data (IPOS Cycle)
Input -> Processing (CPU) -> Output
