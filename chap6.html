     Chapter 6: Web Technology

Definition of Web Technology
Web technology refers to the tools, languages, software, and protocols used to create, transmit, and display content over the Internet.

Fundamental Concepts of the Web

Internet: A global network of interconnected computer systems that exchange data.

World Wide Web (WWW): A collection of interlinked multimedia web pages accessed via the Internet using a browser.

Web Server: A computer system that hosts website files and serves them to clients over the network.

Web Browser: Client software used to request, retrieve, and render web pages (e.g., Google Chrome, Mozilla Firefox).

Core Web Development Components

HTML (HyperText Markup Language): The standard markup language used to structure the static content of a web page.

CSS (Cascading Style Sheets): The design language used to control layout, colors, fonts, and visual appearance.

JavaScript: A client-side scripting language used to create interactive features, handle events, and build dynamic web pages.

Web Addressing and Protocols

URL (Uniform Resource Locator): The specific web address used to identify a resource on the Internet.

HTTP (HyperText Transfer Protocol): The set of rules governing data transfer between web browsers and servers.

HTTPS (HyperText Transfer Protocol Secure): The encrypted version of HTTP that protects data transfers using SSL/TLS security.
