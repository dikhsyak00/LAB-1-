     Chapter 3: Computer Software and Operating System

Definition of Computer Software
Software is a set of programs, procedures, and rules that tell computer hardware how to perform specific tasks and process data into useful information.

Categories of Software

System Software: Programs that manage and support computer hardware and basic operations (e.g., Operating Systems, Device Drivers, Utility Programs).

Application Software: Programs designed to help users perform specific tasks (e.g., Word Processors, Web Browsers, Games).

Operating System (OS)
An operating system is the core system software that acts as an interface between the user, application software, and computer hardware.

Functions of an Operating System

Processor Management: Allocates CPU time to different programs through scheduling.

Memory Management: Tracks and controls main memory (RAM) allocation for active applications.

File Management: Manages data storage, organization, creation, and directory structures on disks.

Device Management: Communicates with input/output hardware using specialized device drivers.

User Interface: Provides a way for users to interact with the system via CLI (text-based) or GUI (graphics-based).

Types of Operating Systems

Single-user vs Multi-user OS: Serves one user at a time or handles multiple users simultaneously.

Single-tasking vs Multitasking OS: Runs a single process at a time or executes multiple applications concurrently.

Real-Time OS: Processes input immediately with strict, predictable time limits.
